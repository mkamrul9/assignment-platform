# Manrope (self-hosted)

Variable WOFF2 files for ReviewDock, loaded through `next/font/local` so production builds do not depend on Google Fonts at runtime.

- License: SIL Open Font License 1.1 — see `OFL.txt`
- Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope)
- Source subset files: Fontsource Manrope variable (latin / latin-ext)

Only the weights and styles referenced by the app are loaded via the variable `wght` axis.
